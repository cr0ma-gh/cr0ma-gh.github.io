# cr0ma-gh.github.io

The website of [Painter](https://github.com/cr0ma-gh/painter), a painting app for
illustration and comics: **https://cr0ma-gh.github.io/painter/**

- `painter/` — the landing page (plain HTML and CSS, no build step), with its
  screenshots and artwork in `painter/assets/`.
- `index.html` — the site root, which forwards to `painter/`.

The download buttons point to the latest GitHub release of Painter
(`releases/latest/download/…`), so a new release needs no change here.
To preview locally, serve the folder with any static server, e.g.
`npx serve .`, and open `/painter/`.
